# Reserva de Asientos - Sala de Cine

**Estudiante:** Fernanda Tipán

## Objetivo
Programa en Python que gestiona la reserva de asientos en una sala de cine
de 3 filas por 4 columnas, usando una matriz. Permite reservar un asiento indicando 
su fila y columna, y muestra el estado completo de la sala.

## Cómo ejecutar
1. Asegúrate de tener Python instalado.
2. Ejecuta el archivo con: `python reserva_cine.py`
3. Ingresa la fila (0 a 2) y la columna (0 a 3) del asiento a reservar.
4. El programa mostrará la matriz de la sala con 0 (libre) y 1 (reservado).
